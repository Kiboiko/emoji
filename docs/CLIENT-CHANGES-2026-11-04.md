## Реализованный объём

- Категории: один ряд; после выбора основной категории показываются её подкатегории, меню «Все категории» и сброс ×.
- Магазины: вместо отдельной надписи рейтинга — значок информации у заголовка. Подсказка про обновление в понедельник в 00:00 МСК закрывается повторным нажатием и нажатием снаружи. Новые золотая/серебряная/бронзовая SVG-рамки, без `#1` перед названием магазина.
- Сортировка перенесена в меню значка внутри поиска. «Продажи» находятся отдельной кнопкой рядом с поиском. В ленте видны последние 14 дней; финансовые заказы и ledger не удаляются.
- Подписки: компактный список каналов; единая форма создания с фото, названием, описанием, ценой, сроком и каналом. Фото выбирается до сохранения. При сбое загрузки/неизвестном результате создания тарифа можно продолжить черновик без повторного создания канала/тарифа.
- Розыгрыши: вход рядом с «Мои подписки», активные сверху, завершённые ниже; фото, название, условия подписки, дата окончания, участие, победитель и username. Описание убрано. NFT-фото импортируется администратором по ссылке `https://t.me/nft/...`. Проверки участия и финальной подписки сохранены; завершённые данные удаляются через 30 дней. Отмена удаляет запись и участников, ставит удаление бот-поста в устойчивую очередь. Если Telegram больше не разрешает удалить старый пост, бот заменяет его нейтральным сообщением без данных розыгрыша и кнопок. Автопост включается явно для конкретного розыгрыша и канала; реальные посты во время проверок не отправлялись.
- «Поделиться»: доступная кнопка-значок в строке названия товара.
- Чат до покупки: значок на витрине продавца, список в «Чатах», текст и приватные фото, непрочитанные сообщения, пагинация, живые обновления, защита повторной отправки. Доступ только у двух участников. 72 часа отсчитываются от первого сообщения; ответы срок не продлевают. Пустой диалог живёт максимум 72 часа от открытия. Данные и фото физически удаляет задача раз в минуту. После оплаты покупки у этого продавца диалог сохраняется по правилам оплаченных чатов; для P2P сообщения и фото переносятся в чат сделки. Финансовая история не удаляется.
- Специальные ссылки: «Админка → Рефералы → Специальные ссылки», несколько ссылок с названием и фиксированным получателем по Telegram ID. Получатель должен уже открыть приложение. Новый пользователь закрепляется при первом входе; повторный вход привязку не меняет. Отключение ссылки запрещает новые привязки, существующие начисления продолжаются.

## Комиссия по специальной ссылке

Уточнение пользователя: при покупке $100 и комиссии $3 получатель получает **все $3**. Реализация направляет 100% фактической комиссии из средств платформы на баланс получателя в Gram. Доля продавца остаётся прежней; обычные реферальные L1/L2 поверх этого не начисляются. За P2P начисление происходит после успешного завершения сделки, при возврате — отсутствует. Подписки перечисляют фактическую комиссию при подтверждённой оплате. Повторная обработка не повторяет выплату; проводки сбалансированы.

Для собственных товаров площадки нет комиссии внешнего продавца: сохранена обычная ставка первого уровня, без второго уровня. Настройки ставок P2P/подписок не изменялись на 3% автоматически; пример клиента определяет долю комиссии, а не меняет глобальные тарифы.

## Дополнение 05.11.2026: пункт 11 — права модератора

В разделе сделок у модератора оставлены только «Споры» и «В эскроу». API без фильтра возвращает только эти статусы, запрос остальных статусов запрещён. - Для рамок рейтинга закреплён порядок слоёв (орнамент поверх фото), SVG-id приведены к безопасному формату. На публичном API Luna корректно имеет rank=2/medal=silver. Браузерная проверка с текущими публичными изображениями показывает золотую, серебряную и бронзовую рамки с номерами. Отдельный сбой конкретного Telegram WebView с исходного скриншота напрямую не воспроизводился.

Проверки именно этой версии: **737 backend-тестов**, 42.68s, отдельная одноразовая PostgreSQL 17 `gram_chat_check_test`; 12 новых сценариев покрывают отсутствие записи при открытии, первую отправку/дедупликацию, старые пустые/истёкшие диалоги, невалидное фото, подписанное обновление/очистку аватара и фотографии двух ролей оплаченной сделки. `npm ci` и production build frontend успешны. На отдельной БД `gram_chat_migrate_test` прошли upgrade всей цепочки, downgrade до a0034inquiries и повторный upgrade; сравнение с ORM без новых расхождений (ранее известные два индекса и trigram исключены). Edge/Playwright: RU 320px dark, RU 390px light, EN 390px dark — полноширинная кнопка, отдельная строка сделок, уход из пустой формы без чата в списке, повтор первого запроса после потерянного ответа, фотографии/заглушки и отсутствие переполнения/ошибок страниц. Telegram/сообщения подменены в этих сценариях.
