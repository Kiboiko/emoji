## Как проверять новые изменения

Для каждого изменённого frontend-приложения выполнить `npm ci`, затем `npm run build` в `frontend/` или `admin/`. Backend проверять `python -m pytest -q` из `backend/` на **отдельной PostgreSQL test DB**; сначала проверить `TEST_DATABASE_URL`, поскольку fixture удаляет и создаёт public schema. Не направлять тесты в рабочую или чужую БД. HTTP/нагрузочные сценарии из [acceptance/README.md](../acceptance/README.md) требуют изолированного подготовленного стенда.
