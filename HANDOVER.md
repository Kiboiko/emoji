# Gram Market — передача проекта

Telegram Mini App — маркетплейс цифровых товаров с оплатой в TON. В интерфейсе
валюта называется **Gram**.

Дата передачи: 9 октября 2026 года. Код в архиве совпадает с версией, которая
работает на тестовом сервере.

---

## Что в архиве

| Папка / файл | Что это |
|---|---|
| `backend/` | Сервер: API, платежи, сделки, подписки, финансы, фоновые задачи, 405 автотестов |
| `frontend/` | Витрина — приложение, которое открывается в Telegram |
| `admin/` | Админ-панель |
| `bot/` | Telegram-бот |
| `nginx/` | Веб-сервер внутри Docker |
| `scripts/` | Резервное копирование и восстановление базы |
| `docs/` | Документация (список ниже) |
| `docker-compose.yml` | Запуск всего проекта одной командой |
| `.env.example` | Шаблон настроек сервера со всеми переменными и пояснениями |

**Чего в архиве нет — намеренно:**

- **Файл `.env` с паролями и токенами.** Секреты не кладутся в архивы и
  репозитории. Перед запуском их нужно выпустить заново (см. ниже).
- **База данных тестового сервера.** Там тестовые заказы, балансы и монеты
  testnet — на боевой сервер их переносить нельзя.

Логотип Gram Market: `frontend/public/icon-512.png` (512×512, подходит для
аватара бота) и `icon-180.png`.

## Что сделано

**Безопасность.** Закрыт служебный вход, который выдавал права администратора
без пароля. Проверка входа через Telegram, защита админки от перебора пароля,
проверка доступа на всех эндпоинтах.

**Оплата в TON через TonConnect** вместо CryptoBot. Покупатель платит из своего
кошелька, курс фиксируется на время счёта. Сервер сам находит платёж в
блокчейне. Недоплата товар не выдаёт, переплата и опоздавший платёж не
теряются.

**Единый баланс в Gram.** Продажи, подписки, реферальные и возвраты копятся на
одном балансе. Вывод — на кошелёк, подключённый в приложении. Администратор
выплачивает одной кнопкой из админки, заявка закрывается сама.

**Магазины.** У каждого товара есть магазин со страницей, рейтингом и
отзывами. Отметка «проверенный» ставится администратором. Ваши собственные
товары продаёт магазин площадки.

**Безопасные сделки между пользователями.** Деньги покупателя заморожены на
счёте площадки, пока он не подтвердит получение. Чат сделки — внутри
приложения, стороны не видят контактов друг друга. Споры разбирает
модератор, продавец может сам вернуть деньги.

**Подписки на закрытые каналы.** Автор подключает канал и задаёт тарифы, бот
выдаёт доступ после оплаты и забирает его по окончании подписки.

**Реферальная программа** с настраиваемыми процентами и вторым уровнем.

**Отзывы** у товаров и магазинов, с публикацией в Telegram-канал.

**Админ-панель:** дашборд, модерация, сделки и споры, каналы, финансы со
сверкой балансов, выплаты, настройки без перезапуска. Работает и с телефона.

**Дизайн витрины:** новое оформление, светлая и тёмная темы, русский и
английский языки, название и логотип Gram Market.

**Надёжность:** двойная запись всех денежных операций с ежедневной сверкой,
резервное копирование базы, 405 автотестов.

Подробные отчёты по этапам — `docs/STAGE-0-REPORT.md` … `STAGE-9-REPORT.md`.

## Что нужно от вас для запуска

1. **Сервер и домен.** Linux-сервер с Docker и свой домен вместо тестового.
2. **Бот.** Токен боевого бота из @BotFather. Если бот уже был у предыдущего
   разработчика — перевыпустить токен командой `/revoke`.
3. **Кошелёк площадки в mainnet.** Адрес, на который будут приходить оплаты.
   С него же администратор будет делать выплаты.
4. **Ключ toncenter для mainnet** — у @tonapibot. Без ключа проверка платежей
   упирается в лимит запросов.
5. **Чат администраторов** — куда приходят заявки на модерацию, споры и
   уведомления о недоплатах.
6. **Канал для отзывов** (если нужен). Бот должен быть в нём администратором.
7. **Текст условий площадки** и **контакт поддержки**. Пока условий нет,
   люди принимают пустой документ, и в споре сослаться не на что.

## Как запустить

Полный порядок — в `docs/DEPLOY-CHECKLIST.md`. Кратко:

```bash
cp .env.example .env
# заполнить .env: секреты, домен, токен бота, кошелёк, TON_NETWORK=mainnet
docker compose -f docker-compose.yml build
docker compose -f docker-compose.yml up -d postgres
docker compose -f docker-compose.yml run --rm backend alembic upgrade head
docker compose -f docker-compose.yml up -d
```

Перед приложением на сервере нужен HTTPS (Caddy или nginx с сертификатом),
который проксирует на порт 8080. В @BotFather боту прописывается адрес
Mini App — ваш домен.

**Обязательно перед запуском:**

- выпустить новые секреты: токен бота, `SECRET_KEY`, пароль базы, пароль
  админки, `INTERNAL_API_TOKEN`;
- `DEBUG=false`, `VITE_DEV_AUTH=false`, `COOKIE_SECURE=true`,
  `TON_NETWORK=mainnet`;
- в админке проверить «Сколько минут ждать оплату заказа» — должно быть 30;
- настроить ежедневный бэкап базы и один раз проверить восстановление;
- пройти покупку, сделку и выплату реальными деньгами на небольшую сумму
  (раздел 7 чек-листа).

## Доступы

Пароли, токены и доступ к тестовому серверу в архив не входят и передаются
отдельно. После передачи рекомендуем:

- сменить пароль админки и пароль `root` на сервере;
- удалить с сервера SSH-ключи разработчиков (`~/.ssh/authorized_keys`).
